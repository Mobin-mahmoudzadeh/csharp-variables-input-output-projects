# Temperature Converter

A robust, console-based utility application developed in C# for converting temperatures between Celsius and Fahrenheit scales. This project demonstrates the fundamentals of input handling, mathematical operations, and data formatting in .NET 8.

## Features
- **Accurate Conversion:** Utilizes precise floating-point arithmetic for temperature calculations.
- **Data Formatting:** Implements custom string formatting to ensure clean and readable output (1 decimal place).
- **User-Friendly Interface:** Clear terminal prompts and structured results.
- **Modern Standards:** Built with .NET 8, leveraging implicit usings and modern C# features.

## Technical Stack
- **Language:** C#
- **Framework:** .NET 8.0
- **Development Environment:** JetBrains Rider

## Mathematical Logic
The application employs the standard linear conversion formula:
$$F = (C \times 9 / 5) + 32$$
