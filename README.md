# C# Variables, Input, and Output Practice Projects

Welcome to my repository for practicing core C# programming concepts. This repository contains **7 distinct console applications** developed using **.NET 8.0** and **JetBrains Rider**. 

The primary focus of these projects is to master foundational concepts including data types (`int`, `double`, `const`), user input handling, arithmetic calculations, and clean output formatting.

## 🚀 Projects Overview

Here is the complete list of the 7 practice applications with their exact project folder names:

| # | Project Folder Name | Description | Key Concepts Covered |
|---|---|---|---|
| 01 | `_01_StudentGradeCalculator` | Calculates final grades or averages based on student scores. | Input conversion, arithmetic average |
| 02 | `_02_AgeCalculator` | Computes the user's age based on their birth year input. | Numeric variable handling, basic subtraction |
| 03 | `_03_TemperatureConverter` | Converts temperatures between different scales (e.g., Celsius and Fahrenheit). | Mathematical logic, float/double operations |
| 04 | `_04_CurrencyConverter` | Converts USD to EUR using a fixed exchange rate. | `const` variables, currency formatting (`:F2`) |
| 05 | `_05_RectangleCalculator` | Computes the area of a rectangle using width and length. | Geometric formulas, `double` precision |
| 06 | `_06_BMICalculator` | Calculates Body Mass Index based on weight and height. | Arithmetic division, variable squaring |
| 07 | `_07_ElectricityBillCalculator`| Generates a utility invoice based on kWh consumption and unit price. | Large numbers, thousands separator (`:N0`) |

- **Language:** C#

## 📐 Key Learning Takeaways
- **Data Integrity:** Knowing when to use `const` for static configuration values versus regular variables.
- **Precision Management:** Utilizing appropriate data types like `double` to prevent precision or rounding loss during calculations.
- **Console UX:** Formatting terminal outputs elegantly using padding, lines, and formatting specifiers (`:N0`, `:F2`).
