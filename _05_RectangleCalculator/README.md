# Rectangle Calculator

A straightforward C# console application to calculate the area of a rectangle. This project reinforces concepts of handling multiple user inputs and performing geometric calculations in a .NET 8 environment.

## Features
- **Dual Input Handling:** Captures both width and length from the user.
- **Precision:** Uses `double` for accurate area calculation.
- **Formatted Results:** Provides clean output rounded to two decimal places.

## Technical Stack
- **Language:** C#
- **Framework:** .NET 8.0
- **Development Environment:** JetBrains Rider

## Geometric Formula
The area is determined by the standard formula:
$$Area = Width \times Length$$
