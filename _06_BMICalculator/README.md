# BMI Calculator

A precise C# console application that calculates the Body Mass Index (BMI) based on user-provided weight (in kilograms) and height (in meters). This project demonstrates the usage of arithmetic division, squaring variables, and numeric output formatting in .NET 8.

## Features
- **Dynamic Calculation:** Handles decimal values smoothly using the `double` data type.
- **Formatted Result:** Displays the final BMI rounded to a clean, single decimal place.
- **Input Validation Ready:** Structured to easily implement future weight category checks.

## Technical Stack
- **Language:** C#
- **Framework:** .NET 8.0
- **Development Environment:** JetBrains Rider

## Mathematical Logic
The application determines the index using the standard health formula:
$$BMI = \frac{\text{Weight (kg)}}{\text{Height (m)}^2}$$
